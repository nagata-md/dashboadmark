# エントランス (Entrance) — spec.md

個人ブランドのアートブックを作り、並べて見せるサイト。 アートブックは Web 上でめくれて、特定部分をクリックすると連携 EC へ飛べる。

---

## 0\. このドキュメントについて

これは Claude Code で実装するための仕様書（v1）。 **「⚠️ 要相談」** が付いた箇所は、実装着手前に人間が決める。それ以外は本書の記述を正とする。

---

## 1\. プロダクト概要

### コンセプト

個人/ブランドのアートブックを、紙の本のように「めくれる」高品質なビューアで見せ、それらをギャラリーとして並べるサイト。アートブックの中の任意の箇所からコラボ商品の EC へ送客できる。

### 提供価値

- **見る人**: SNS の断片ではなく、ブランドの世界観を1冊の「本」として没入体験できる。  
- **ブランド**: 自分の世界観を編集された誌面として提示し、その流れのまま物販へ繋げられる。  
- **運営**: アートブックを「並べる場（=エントランス）」として運営する。

### 最重要要件

**めくり心地（操作感）が品質の核**。参照基準は publuu レベルの滑らかさ。ここが安っぽいとプロダクトが成立しない。

---

## 2\. ユーザーとロール

| ロール | 説明 | 認証 |
| :---- | :---- | :---- |
| 閲覧者 (Visitor) | ギャラリーを見てアートブックをめくる | 不要 |
| 運営 (Admin) | PDF 入稿・ホットスポット設定・公開管理を行う（=お友達と本人） | 必要（Supabase Auth \+ 許可メール制） |
| ブランド (Brand) | アートブックの帰属先。v1 ではログインせず、運営が代理で登録・入稿する | v1ではなし |

v1 ではブランド自身のログイン/編集機能は作らない（後回し）。

---

## 3\. 用語定義

- **アートブック (Artbook)**: 1冊の本。複数ページからなる。各人/ブランドの「Entrance（入口）」として提示される。  
- **ページ (Page)**: アートブックを構成する1ページ単位の画像。  
- **ホットスポット (Hotspot)**: ページ上の矩形領域。クリックすると指定 URL（主に外部 EC）へ飛ぶ。  
- **ギャラリー (Gallery / Newest)**: アートブックを編集的に並べて見せるトップ。  
- **Entrance 種別（ロール）**: 各アートブックの分類ラベル（Artist's / Craftman's / Designer's / Model's Entrance …）。  
- **CornerStore**: ショップ（コラボ商品の入口）。**Journal**: 読みもの。詳細は §10。

## 4\. 主要機能

### 4.1 アートブック・ビューア（最重要）

- ライブラリ: **StPageFlip 系**（`react-pageflip` / `HTMLFlipBook`）。リアルなページめくり・影表現・スワイプに対応。  
  - ⚠️ 要相談: `react-pageflip` 本家はメンテが滞り気味との情報あり。実装前に最新の保守フォークを評価して採用版を確定する。  
- ページは**画像ベタ貼りにしない**。各ページを `<div class="page">` とし、内部に  
  1. 背景としてページ画像 `<img>`  
  2. その上に**ホットスポットの `<a>` を相対座標 (%) で absolute 配置** を重ねる。`clickEventForward: true` によりページ内 `<a>` のクリックが有効になる。  
- 操作:  
  - ドラッグ/スワイプ/クリックでめくり  
  - キーボード ←→ でめくり  
  - モバイルは単ページ表示に自動切替（`usePortrait`）、`mobileScrollSupport` で誤スクロール防止  
  - **ズームは v1 では実装しない（決定済み）**。プロダクトの核は「めくり心地」であり、そこに集中する。  
- パフォーマンス:  
  - 表紙を優先読み込み（LCP 最適化）  
  - 現在ページ±1〜2 を先読み（preload）  
  - 画像は WebP・適切解像度（Retina 考慮で 2x まで）

#### 4.1.1 操作感の品質基準（最優先・page-flip 設定）

採用コア: **`page-flip` (StPageFlip) v2.0.7（確定）**。React 統合時もラッパーはこのコアを包むだけなので、挙動の基準はコア設定で定義する。 「気持ちよさ」は下記パラメータで決まる。プロトタイプ（`entrance-flip-demo.html`）で実機検証し、**確定値をここに上書き固定**する。

**既知の制約（受容済み）**: page-flip は折れ目を必ずページの四隅いずれかに固定する幾何カール方式で、掴んだ点（中央など）からは折れない。指追従カール（中央から曲がる）は WebGL 物理エンジン系（DearFlip 等／有料・別系統）が必要だが、**v1 では採用しない**。代わりに UX で補う:

- PC は見開き表示にして、自然と外側の角へ手が伸びるようにする  
- 待機中の角に折れかけのページ端（ドッグイヤー）＋コーチマークを表示し、最初の操作で消す  
- タップでめくり / 前後ボタン / キーボード ←→ を併設し、ドラッグ位置に依存しない導線を用意する

| パラメータ | 役割 | 暫定既定値 | 備考 |
| :---- | :---- | :---- | :---- |
| `flippingTime` | 1枚めくり切る時間(ms) | **800**（要検証） | 短い=キビキビ / 長い=優雅。publuu 体感は概ね 600–900ms |
| `maxShadowOpacity` | めくり中の影の最大濃度(0–1) | **0.5**（要検証） | 折れ目とページ裏の影。高=重い / 低=立体感が消える |
| `drawShadow` | 影描画の有無 | `true` | 影なし比較用にオフ可。本番は true |
| `showCover` | 表紙/裏表紙を厚紙(ハード)扱い | `true` | ハードカバーの単独表示で「本」らしさ |
| `usePortrait` | 縦持ち時に単ページ化 | `true` | モバイル必須 |
| `mobileScrollSupport` | 本に触れた時のスクロール抑制 | `false` | めくり優先（誤スクロール防止） |
| `clickEventForward` | ページ内 `<a>`/`<button>` のクリック透過 | `true` | **ホットスポット成立の前提** |

品質チェック（受け入れ条件に反映）:

- [ ] めくりが滑らか（カクつき・チラつきがない / 目標 60fps）  
- [ ] めくり中、折れ目とページ裏に**自然な影**が出る（紙が立体に見える）  
- [ ] 表紙・裏表紙がハードカバーとして単独で立つ  
- [ ] **ドラッグ＝めくり / タップ＝リンク**が誤爆なく両立する（ホットスポットのタップでめくりが暴発しない）  
- [ ] モバイルで単ページ、PC で見開き、サイズ可変で崩れない

### 4.2 ギャラリー / 一覧（トップ \= Newest）

- 公開済みアートブックを**写真フルブリードのエディトリアル・マソンリーグリッド**で並べる（サイズ可変のタイル混在、タイル間はほぼ詰め）。  
- 各カード: 表紙写真 \+ 下部に**ロール表記**（"Artist's Entrance" 等）+ **セリフ見出し**（=アートブックのタイトル）。可読性のため写真下部に薄いスクリム。  
- カードをクリックで**アートブック・ビューア**（めくり）へ遷移。  
- 並び順は運営が `sort_order` で制御（既定は新着順）。  
- 末尾に中央寄せの **「Would you like to go shopping?」**（青リンク）→ 外部 EC ストア（= CornerStore）。  
- デザインの基準は §12。

### 4.3 ブランドページ

- `/b/[brandSlug]`：ブランドのプロフィール（名前・紹介・外部リンク）+ そのブランドのアートブック一覧。

### 4.4 アートブック入稿（ページ画像を入稿）

- **PDF → 画像の変換は運営側で実施する**（プロダクト内では変換しない）。アプリは**変換済みのページ画像**を受け取る。  
- 運営が管理画面で、順序付きのページ画像（WebP/PNG）をアップロード → Supabase Storage に保存 → ページ情報を DB に記録。  
- アップロード時に各ページの幅・高さと縦横比 (`aspect_ratio`) を記録（ホットスポット座標の基準になる）。  
- **容量・ページ数の上限は設けない**（決定済み）。

### 4.5 ホットスポット設定（ビジュアルエディタ・v1）

- 管理画面の本エディタで、**ページ画像の上をドラッグして矩形を描き**、その場でリンク先（外部 EC の URL）とラベルを設定する。  
- 既存のホットスポットは**選択して移動・リサイズ（ハンドル）・削除**できる。1ページに複数可。  
- 保存時に、描いた矩形を**ページ基準の相対座標 0.0〜1.0 に変換**して保存（表示サイズに依存しない）。閲覧側は相対座標を画像上へ絶対配置で復元するので、PC/スマホで枠がズレない。  
- エンジニアでない運営が日常的に触る画面なので、操作はクリック&ドラッグで完結させる（JSON を手で書かせない）。  
- 保存形式（`pages.hotspots` jsonb）は下記。エディタがこの JSON を生成・編集する:

```
// pages.hotspots (jsonb) の中身
[
  {
    "id": "hs_01",
    "x": 0.12,        // 左上 X (0..1, ページ幅基準)
    "y": 0.34,        // 左上 Y (0..1, ページ高さ基準)
    "w": 0.30,        // 幅 (0..1)
    "h": 0.10,        // 高さ (0..1)
    "href": "https://shop.example.com/items/123",
    "label": "コラボTシャツ",   // aria-label / ホバー表示用
    "target": "_blank"           // 既定 _blank, rel=noopener noreferrer
  }
]
```

### 4.6 EC 連携（外部リンク）＋ クリック計測

- v1 は**外部 EC へリンクで飛ばすだけ**（BASE / STORES / Shopify など、ブランドが持つ任意の URL）。  
- サイト内カート・決済は作らない。  
- グローバルナビの **CornerStore** と「Would you like to go shopping?」は、いずれも**外部 EC ストアへのリンク**（専用ページは作らない）。  
- **クリック計測（v1 で実装・決定済み）**: ホットスポットがクリックされたら、外部 EC へ遷移する前に `navigator.sendBeacon('/api/track', …)` で記録する。  
  - 記録項目: `artbook_id` / `page_index` / `hotspot_id` / `href` / `referrer` / 匿名 `visitor_key`（cookie 等。個人情報は持たない）。  
  - 集計: 管理画面で「本ごと・ページごと・ホットスポットごとのクリック数」を閲覧。送客効果をブランド提案に使う。

## 5\. 画面一覧と遷移

**グローバルナビ**: `Newest`（トップ＝最新の Entrance 一覧）/ `CornerStore`（ショップ）/ `Journal`（読みもの）。ロゴは緑のワードマーク（アーチ＝開いた本のグリフ付き）。

**公開側**

- `/` … ギャラリー（Newest / アートブック一覧）  
- `/b/[brandSlug]` … ブランドページ  
- `/book/[bookSlug]` … ビューア（フルスクリーンめくり）

ナビの `CornerStore` は**外部 EC ストアへのリンク**（専用ページは作らず、外部 URL へ遷移）。`Journal` は **v1 ではラベルのみのプレースホルダー**（中身は作らない）。"Would you like to go shopping?" の青リンクも CornerStore と同じ外部 EC へ。

**管理側（要ログイン）**

- `/admin` … ログイン  
- `/admin/brands` … ブランド CRUD  
- `/admin/books` … アートブック一覧  
- `/admin/books/[id]` … ページ画像入稿 / ページ確認 / **ホットスポット・ビジュアルエディタ** / 公開・非公開切替 / ロール（Entrance種別）設定  
- `/admin/analytics` … クリック計測の集計（本・ページ・ホットスポット別）

## 6\. データモデル（Supabase / Postgres）

```
brands
  id            uuid pk
  slug          text unique
  name          text
  bio           text
  avatar_url    text
  links         jsonb   -- [{ "type": "x", "url": "..." }, ...]
  created_at    timestamptz

artbooks
  id            uuid pk
  brand_id      uuid fk -> brands.id
  slug          text unique
  title         text
  description    text
  cover_image_url text
  entrance_type text             -- ロール表記。'artist'|'craftman'|'designer'|'model' …（拡張可）
  aspect_ratio  numeric          -- width / height（全ページ共通前提）
  status        text             -- 'draft' | 'published'
  sort_order    int
  published_at  timestamptz
  created_at    timestamptz
  updated_at    timestamptz

pages
  id            uuid pk
  artbook_id    uuid fk -> artbooks.id
  index         int              -- 0始まりのページ順
  image_url     text
  width_px      int
  height_px     int
  hotspots      jsonb            -- 4.5 のスキーマ。既定は []
  created_at    timestamptz

hotspot_clicks                    -- クリック計測（v1）
  id            uuid pk
  artbook_id    uuid fk -> artbooks.id
  page_index    int
  hotspot_id    text             -- hotspots[].id
  href          text
  referrer      text  null
  visitor_key   text  null       -- 匿名識別（個人情報は持たない）
  created_at    timestamptz
```

- **RLS**: 公開側は `status = 'published'` のみ読み取り可。書き込みは Admin のみ。`hotspot_clicks` は匿名 insert を許可し、読み取りは Admin のみ。  
- Storage: `artbooks/{artbook_id}/pages/{index}.webp`、`covers/{artbook_id}.webp`。

## 7\. 技術スタック

- フロント/サーバー: **Next.js (App Router)** / TypeScript  
- DB・認証・ストレージ: **Supabase**（Postgres \+ Auth \+ Storage \+ RLS）  
- ホスティング: **Vercel**  
- ビューア: **page-flip (StPageFlip) v2.0.7**（確定）  
- ページ画像: 運営側で PDF から変換済みのものを入稿（プロダクト内で PDF 変換はしない）  
- スタイル: Tailwind CSS（デザイントークンは §12 / `entrance-home.html` を基準に theme へ）  
- フォント: Archivo（sans・ワードマーク/ナビ/ラベル）/ Fraunces（serif・見出し）。Google Fonts。  
- 認証ガード: Admin は許可メールのリストで制限  
- 計測: `navigator.sendBeacon` → `/api/track`（Supabase へ insert）

## 8\. 非機能要件

- **操作感最優先**: めくりは滑らかに（目標 60fps）。`flippingTime` ・影強度はチューニング前提。  
- **表示速度**: 表紙 LCP 最適化、隣接ページ先読み、WebP、CDN 配信。  
- **レスポンシブ**: モバイル / タブレット / PC。モバイルは単ページ。  
- **SNS シェア (OGP)**: 各 book・各ブランドに表紙ベースの OGP 画像。拡散時に「映える」ことを重視。  
- **アクセシビリティ**: キーボード操作、ホットスポットに `aria-label`。  
- **SEO**: book/ブランドページはメタ情報を適切に出力。

## 12\. ビジュアルアイデンティティ（デザイン）

**視覚の基準ファイル: `entrance-home.html`（トップページ・プロトタイプ）**。提供モックを実装に起こし方向を確定したもの。色・字組み・カード構造・余白はこのファイルを正とする（写真は実画像が入る前提のプレースホルダー）。sabukaru 系の上質な編集メディアの空気。**写真が主役**で、UI は静かに支える。

### カラー（確定値 / 緑のみ実ロゴで微調整可）

- 背景: 白 `#FFFFFF`  
- ブランドグリーン（ワードマーク / ナビ / フッターのグリフ）: `#1B7A3C`  
- 写真上の見出し・ラベル: 白 `#FFFFFF`（可読性のため写真下部にスクリム）  
- ショッピング導線リンク: 青 `#2B53D6`（下線つき）  
- 補助テキスト（フッター等）: 中間グレー `≈ #9C968C`

### タイポグラフィ

- ワードマーク "ENTRANCE" / ナビ / ロール表記: **Archivo**（700–800、字間 `.10em` 程度）。上に**アーチ＝開いた本のグリフ**（SVG）。  
- カード見出し（=アートブックのタイトル）: **Fraunces**（500、ハイコントラスト）。白・写真上に重ねる。サイズは `clamp(18px,1.5vw,27px)`。  
- ロール表記・ラベル: Archivo 600、オールキャップ＋字間広め（`.16em`）。例: "Artist's Entrance"。  
- フォントは Google Fonts（Archivo / Fraunces）。読めない環境では `Hoefler Text`/Georgia 系・grotesque 系へフォールバック。

### レイアウト

- トップ（Newest）は**写真フルブリードのマソンリーグリッド**。デスクトップ 3 列 / タブレット 2 列 / モバイル 1 列。タイル間 `gap: 8px`（ほぼ詰め）、左右は画面端までフルブリード。  
- タイルは縦横比混在（`4/3` `16/10` `3/4` `2/3`）で編集的なリズムを作る。  
- **カード構造**: 写真（背景）＋下部スクリム `linear-gradient(to top, rgba(0,0,0,.66), transparent 58%)` ＋ロール表記＋セリフ見出し。見出しは左寄せ/右寄せをタイルごとに混ぜる。  
- ページ末尾に中央寄せの **「Would you like to go shopping?」**（青・下線）→ 外部 EC ストア。  
- フッター: 開いた本のグリフ（緑）、`©ENTRANCE All rights reserved`、`Powered by Standby Inc.`、`About` / `Instagram`。

### モーション

- 控えめ。カードホバーで写真を微かにズーム（`scale(1.045)` / `transition .7s`）。`prefers-reduced-motion` を尊重。

### 実装メモ

- トークン（色・フォント・gap・縦横比・スクリム）は Tailwind の theme / CSS 変数に落とす。  
- グリッドは列マソンリー（`columns`）が既定。特定タイルを主役にする配置に変える場合は §10 の調整対象。
